# VNN Game of Life (GoL) Model

## Overview
This document describes the implementation of a full Von Neumann Network (VNN) model capable of learning the Game of Life (GoL) transition rules directly on the GoL grid. 

The model is designed to take an entire 64x64 GoL grid state as input and predict the full next 64x64 grid state (the next frame). The model learns from training data generated by simulating the GoL rules using various complex initial patterns.

## Implementation Details

The implementation is provided in the script `test_jax_vnn_full_gol.py`.

### 1. Data Generation Pipeline
To thoroughly train the model to approximate the 3x3 neighborhood transition rules of GoL, a dynamic dataset is generated prior to training.
- **Pattern Variety:** For each sample trajectory, the script randomly selects between five classical GoL patterns:
  - `Blinker` (3x2 footprint, static oscillator)
  - `Glider` (3x3 footprint, diagonal spaceship)
  - `Toad` (4x4 footprint, static oscillator)
  - `Pulsar` (13x13 footprint, static oscillator)
  - `GliderGun` (10x37 footprint, complex spaceship generator)
- **Safe Initial Placement:** The randomly selected pattern is inserted into a blank 64x64 grid. The initial insertion coordinate (`rx`, `ry`) is randomized, but heavily buffered by `l_steps` (the number of evolution steps) on all four boundaries. Since the "speed of light" in cellular automata is 1 cell/step, this padding guarantees that moving patterns (like gliders) never collide with or get cropped by the grid edge during the trajectory.
- **Evolution Trajectories:** The grid is evolved for a fixed trajectory length (`l_steps = 8`) using the ground-truth GoL simulator (`evolve.evolve_fast`). Each step in the evolution provides a ground-truth $(X_t, X_{t+1})$ pair.
- **Dataset Size:** By default, it generates 12,800 training samples formatted as full 64x64 JAX/NumPy grids.

### 2. Model Definition
The model leverages the `UniverseLP` architecture to simulate cellular operations across the GoL grid:
- **Universe Grid Size ($N$)**: 64x64.
- **Input & Output Size**: 64x64, mapping identically 1-to-1 onto the universe grid.
- **Kernel Size**: Fixed at 3x3 to directly mimic the fundamental Moore neighborhood of Conway's rules.
- **Depth**: 2. A shallow depth is sufficient because GoL relies strictly on immediate neighborhood interactions at each discrete time step.
- **Green's Functions (Filters)**: 64 direction filters are learned during training to govern spatial signal routing.
- **Activations**: `tanh` for internal hidden signal propagation and `None` (no activation) for the final step, removing the `sigmoid` bottleneck which was hindering convergence.

### 3. Training Procedure
The network is trained as a straightforward regression-like system using a batched training loop:
- **Batches & Epochs:** The 12,800 samples are iterated over 50 epochs with a batch size of 128.
- **Shuffling:** The dataset of $(X_t, X_{t+1})$ pairs is rigorously shuffled at the start of every epoch to prevent catastrophic forgetting and sequence memorization.
- **Loss Function:** Mean Squared Error (MSE) is employed to penalize differences between the predicted continuous grid values and the discrete binary ground truth next frame.
- **Optimizer:** The model utilizes `AdamW` along with an `optax.warmup_cosine_decay_schedule` (starting at 0.001, peaking at 0.03 after 2.5% warmup, and decaying to 0.0005) to help the model escape early local minima.
- **Evaluation:** Every 10 epochs, the model is evaluated. The continuous sigmoid predictions are explicitly rounded to `uint8` (`0` or `1`) integers, and an exact pixel-perfect accuracy score is computed over the first 1000 items in the training set to track convergence progress.

### 4. Output and Verification
Upon completion, the script exports the following artifacts to the root directory for validation:
- `vnn_full_gol_filter.png`: A grid plot displaying all 32 learned direction filters (Green's functions).
- `vnn_full_gol_states_final_thres.png`: A visualization of the final thresholded states of the VNN cells.
- `vnn_full_gol_animation.gif`: An animated GIF of a Glider evolving recurrently (passing the output of the model back in as the input) entirely driven by the trained VNN, demonstrating its capacity to sustain complex rules over arbitrary timescales independent of the true simulator.
